# AMBOSS QBank

مستودع مصدر موقع AMBOSS QBank على GitHub Pages. ملف `AMBOSSQBank.html.gz` هو أرشيف GZip مطابق بايتًا ببايت لملف HTML المرفق. يُعاد تكوين الملف إلى `_site/index.html` أثناء GitHub Actions ويُنشر كصفحة ويب عادية؛ لا توجد شاشة تحميل وسيطة.

حُفظ المصدر مضغوطًا لأن HTML الأصلي حجمه نحو 396 MB ويتجاوز حد GitHub للملف الواحد البالغ 100 MiB. حجم الموقع المنشور الناتج أقل من حد GitHub Pages الإجمالي البالغ 1 GB. لتشغيل النشر يدويًا، افتح **Actions → Deploy AMBOSS QBank to GitHub Pages → Run workflow**.
