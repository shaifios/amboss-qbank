# AMBOSS QBank

موقع بنك الأسئلة على GitHub Pages. تفتح الصفحة الرئيسية بواجهة خفيفة وفهرس الاختبارات، ثم تُحمَّل بيانات الاختبار المختار فقط من `tests/<test-id>.json` عند فتحه. باني التدريب المخصص يحمّل الاختبارات التي يحددها المستخدم فقط، والبحث عن QID يستخدم فهرسًا مختصرًا لا يحتاج إلى تحميل كل الأسئلة.

تتضمن الصفحة زر **Download full offline HTML** لتنزيل نسخة `AMBOSSQBank.html` كاملة ومستقلة للعمل دون اتصال. يحتفظ المستودع أيضًا بالمصدر المضغوط الأصلي `AMBOSSQBank.html.gz`. بيانات الاختبارات مُقسّمة أثناء البناء من هذا المصدر؛ المخرجات المتوقعة 1,266 اختبارًا و21,247 سؤالًا.

لإعادة بناء ونشر الموقع: افتح **Actions → Deploy AMBOSS QBank to GitHub Pages → Run workflow**. يُنشئ `build_site.py` الصفحة والملفات المقسمة ونسخة HTML الكاملة القابلة للتنزيل، ثم ينشرها GitHub Pages. يحتاج إصدار الموقع إلى اتصال بالإنترنت لتحميل ملف الاختبار المختار؛ أما ملف HTML الكامل الذي يُنزّل من الزر فيعمل مستقلًا دون اتصال.
